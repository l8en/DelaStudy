# Student lens setup

## Direction

Serve high-school and introductory-college students who want to start useful study work, not configure a dashboard. The first decision is their academic starting point; the endpoint is a real course and a usable study rhythm.

Three recognizable decisions:

- An optical aperture opens as the seven setup stages are completed. It visualizes setup progress; no idle mascot or random sphere.
- The completed instrument becomes Today's daily Focus dial. Its ring and aperture encode saved minutes against the student's own goal; tapping it starts or resumes Focus.
- Navigation is question → choice → preview → desk, rather than a long informational form. Authentic course imagery remains the route into learning content.

## Account and setup flow

Create a unique username and password first. Then select year, main goal, subjects, academic route, optional school, daily minutes, work/break rhythm and starting sound. Preview/change the actual starting course and optionally add the first planner task. No notification permission or audio playback is requested during setup.

Each required setup change is saved atomically in that account's progress file. Relaunch/login resumes the saved stage and choices. Completion applies preferences, saves the course and clears the draft in one update. Existing accounts without a draft are not forced through onboarding. Recovery preserves the unfinished draft and account ID.

School remains optional and private by default; home study and outside-Delaware routes are available. The existing directory is partial, not verified enrollment. AP, honors and SAT/ACT labels describe the existing preparation/support scope, not accreditation or a complete official curriculum.

## Settings

The main list contains Account, Study preferences, Focus & Zen, Notifications & Lock Screen, and About & data. Sign-out is a separate action. Advanced long-break/feedback controls and per-account reset live one level deeper. The Focus screen retains session controls and presets, not the entire preferences wall.

Reopening Study preferences is an editable draft: Cancel or dismiss leaves saved choices unchanged. Save applies the full plan without deleting learning records. Notifications remain opt-in; iOS Focus must be enabled by the user through system controls.

## Motion and readability

One spring coordinates selection, stage changes and aperture progress; Reduce Motion uses static geometry and simple fades. There is no continuous animation on Today or setup. Safe-area actions stay available while scrolling; accessibility text uses single-column choices and reflowing summaries. Number/dash navigation prefixes are removed without editing academic source text, mathematical expressions, citations or stable IDs.

Verification and remaining device/review gates are recorded in STATUS.md. No ordinary account data is reset to demonstrate this flow.
