# One-tap lesson entry

Native iPhone 14 Simulator captures from isolated test accounts, not mockups.

- [Today](Today.png): the next lesson and Start/Continue action come before timers and imports. Compare [the previous order](../StudentSetup/Today.png) at the same device size and zero-XP U.S. History starting state.
- [Course start](Course-start.png): the primary lesson action is above the image and outline.
- [Focus offer inside the lesson](Focus-offer.png): Enable starts the linked timer without leaving the reader; Disable leaves Focus off. The notice is non-blocking and does not return on revisits, practice transitions or login.
- [The preference](Preference.png): Profile → Settings → Focus & Zen → Offer Focus for new lessons. The switch is saved per account.
- [Actual iOS larger text and dark appearance](Today-accessibility.png) and [the Focus offer with native Reduce Motion](Focus-offer-accessibility.png). The original Simulator settings were restored after the checks.

An existing timer is never replaced by opening another lesson. Timer controls remain in the lesson toolbar. These are app Focus sessions, not automatic control of iPhone system Focus.
