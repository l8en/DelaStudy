# Course image credits

35 source assets cover 39 published courses. Images retain their individual licenses; resizing, JPEG compression, and display crops do not remove attribution or share-alike conditions. No endorsement is implied. Course covers include photographs, micrographs, archival documents, a historical print, a map reproduction, and a satellite image; they are not all ordinary camera photographs.

Full acquisition URLs, provenance, accessibility descriptions, focal points, and relevance notes: [bundled catalog](../Sources/FirstStateCore/Resources/CourseMedia/catalog.json). Editorial selections: [course-image-selections.json](course-image-selections.json). Source records accessed October 24, 2026.

## Reproduction

Run `node scripts/course-media.mjs records`, then `node scripts/course-media.mjs acquire`, then `node scripts/course-media.mjs validate` from the repository root. Node, curl, and macOS sips are used; no API keys or generation service are required. Requests are throttled and may need to be resumed after public-service rate limits. Cached source records and downloads live in the system temporary directory, not in the app. The selected file names and URLs allow reacquisition.

Use `swift scripts/media-contact-sheet.swift` to create review sheets in /tmp. Run `swift test` for course mapping, provenance fields, local JPEG decoding, dimensions, and the shipping-image budget.
