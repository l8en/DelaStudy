References and aliases

A variable of a reference type holds a reference to an object, or null. Assigning one reference variable to another does not copy the object. Both variables can refer to the same mutable object, so a mutation through one is visible through the other. Reassigning one variable to a different object changes only that variable's reference. Drawing arrows from variables to objects clarifies this distinction.

Worked example

If Counter b = a; and both refer to one Counter, b.increment() changes that object's value, observable through a. But b = new Counter(); makes b refer to a new object without moving a.
