Nested loops and complexity

Nested loops combine repetitions. If an outer loop executes n times and each iteration runs an inner loop m times, the inner body executes n×m times. If the inner bound depends on the outer index, sum the varying counts rather than multiplying by a fixed bound. Big-O describes asymptotic growth, not an exact measured runtime on a phone or laptop.

Worked example

for (int i = 0; i < n; i++) for (int j = 0; j < n; j++) visits n² pairs. If instead j starts at i + 1, it visits n(n−1)/2 distinct unordered index pairs, still O(n²).
