Count-controlled loops

A for loop evaluates its initializer once, then checks the condition before each iteration, executes the body, and performs the update. The condition determines whether an endpoint is included. Loops with index < length visit indices 0 through length−1. Track how many times the body executes rather than counting punctuation or condition checks.

Worked example

for (int i = 0; i < 4; i++) executes with i equal to 0, 1, 2, and 3. The body runs four times; the condition is checked a fifth time and fails.
