Accumulators and invariants

An accumulator combines values across iterations. Initialize it to an identity appropriate to the operation: zero for a sum, one for a product. A loop invariant describes a fact maintained through iterations and can justify the final answer. Be careful not to reset an accumulator inside the loop unless that reset is intentional.

Worked example

int sum = 0; for (int i = 1; i <= 4; i++) sum += i; produces partial sums 1, 3, 6, 10. After processing i, sum equals 1 + 2 + ... + i.
