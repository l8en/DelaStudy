Selection and boundary cases

An if statement chooses an action based on a boolean condition. An if/else chain executes the first matching branch and skips later branches. Separate if statements are tested independently. Test boundary values exactly at thresholds and just to either side. Braces make branch ownership explicit and prevent mistakes when statements are added.

Worked example

For if (score >= 90) grade = "A"; else if (score >= 80) grade = "B"; else grade = "C";, a score of 90 follows the first branch.
