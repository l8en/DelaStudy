Classes and encapsulation

A class defines a type with fields and behavior. Each ordinary object has its own instance-field values. Constructors initialize new instances. Private fields and public methods can protect valid state, but a class is not automatically correct just because fields are private. Describe an invariant, such as a balance never being negative, and make each modifying method preserve it.

Worked example

Two Counter objects can each hold a private int value. Incrementing one object's field does not change the other's field. A static field, in contrast, belongs to the class rather than to each individual object.
