Searching and edge cases

Linear search checks elements one by one and can stop when a match is found. If no match appears, it reports absence explicitly, often using −1 for an index. Test an empty array, a match at either end, duplicates, and no match. Binary search requires sorted data and a consistently shrinking search interval; applying it to an unsorted array is not reliable.

Worked example

Searching {8, 3, 8, 1} from left to right for 8 returns index 0 if the algorithm stops on its first match. A different specification might request every match, so define the desired result first.
