Check errors and protect information

Reviewing financial records helps distinguish accurate information, mistakes, and possible identity misuse. If an account looks unfamiliar, investigate through trusted official contact channels rather than responding to an unexpected message that demands sensitive details. Keep copies of relevant records and use the official dispute guidance linked from the source. Specific procedures and protections can change; this lesson does not substitute for current instructions. Passwords, verification codes, and account numbers should not be sent to someone merely because a message sounds urgent.

Worked example

In a hypothetical message, someone claims a credit-report error can be fixed immediately if a student shares a login code. Urgency and a request for a security code are reasons to stop and independently contact the actual provider.
