Strings and concatenation

String is a reference type representing an immutable sequence of characters. Concatenation with + joins text, including the text representation of numeric operands. Addition and concatenation group left to right, so parentheses can change a result. Use .equals to compare String contents; == compares reference identity for objects. Do not rely on string interning to make == appear reliable.

Worked example

"Score: " + 2 + 3 yields "Score: 23". "Score: " + (2 + 3) yields "Score: 5" because the numeric addition occurs first.
